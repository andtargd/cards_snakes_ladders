Запуск игры локально

Cards, Snakes & Ladders: обычная веб-версия и версия для CrazyGames. Все команды выполняются из корня проекта.

Что нужно

  • Python 3: на нём работают и сервер, и сборка.
  • Любой современный браузер.
  • npm, Node и сборщик не нужны. three.js и PeerJS уже лежат в vendor/, с CDN ничего не грузится.

1 Веб-версия (как на GitHub Pages)

Запустите сервер и не закрывайте терминал:

python tools/server.py 5500

Откройте http://localhost:5500/.

Двойной клик по index.html не сработаетЧерез file:// браузер не загрузит ES-модули, поэтому нужен сервер.
Порт занят?Возьмите другой, например python tools/server.py 5510, и замените порт во всех ссылках ниже.

Подойдёт и любой статический сервер (python -m http.server 8765), но с tools/server.py работают ещё и все тестовые страницы из tools/.

2 Версия для CrazyGames

Есть два способа: быстрый, без сборки, и полный, с настоящим архивом.

Быстро · без сборки

Профиль CrazyGames

Добавьте к обычной странице параметр:

localhost:5500/?platform=crazygames

Подходит, чтобы проверять поведение игры. Изменения в коде видны сразу после перезагрузки.

Полный · со сборкой

Архив + рамка портала

Собирается настоящий zip, затем сборка открывается в iframe тех размеров, на которых тестирует CrazyGames.

Подходит для проверки перед загрузкой на портал.

Полная проверка по шагам

  1. Соберите архив: 
    python tools/build_cg.py
    Скрипт остановится с ошибкой, если что-то грузится по абсолютному пути. В конце он печатает число файлов и размер.
  2. Проверьте, что сервер из шага 1 запущен.
  3. Откройте рамку: localhost:5500/tools/cgframe.html. Справа вверху показано время до появления меню.
  4. Пройдите по размерам из выпадающего списка. Если рамка больше окна, включите fit. Кнопка Reload перезапускает игру.
  5. Загрузите dist/crazygames.zip на портал CrazyGames.
Сборка не обновляется самаПосле каждого изменения кода снова запустите build_cg.py, иначе в рамке будет старая версия.

Снимки всех экранов на всех размерах

tools/shots.html по очереди открывает игру (index.html, не сборку) в рамке каждого размера при DPR 1, выводит на экран меню, Solo Play, Pass & Play, Online, How to Play, The Cards, партию на 6 игроков на поле 100, руку из 4 карт, выбор цели, лог, конец партии, игровое меню и другие, и сохраняет PNG в tmp/shots/now/. Полный прогон (10 размеров QA и 3 телефонных) идёт около 12 минут.

ПараметрЧто делает
sizes=821x462,390x844только эти размеры (по умолчанию все)
screens=menu,game,targetтолько эти экраны (по умолчанию все; список в начале страницы)
out=tmp/shots/afterкуда сохранить
dpr=2плотность пикселей (по умолчанию 1)
safe=47,0,34,0изобразить вырез и полоску «домой» телефона: отступы сверху, справа, снизу, слева

Последние два параметра понимает и сама игра: localhost:5500/?dpr=1&safe=0,44,21,44. С ?dpr= игра не снижает разрешение на медленной машине; ?dpr=2&adapt снижает, как обычно.

SDK CrazyGames пока не подключёнВ web/platform.js для него есть заглушки, работают пока только mute и unmute. Поэтому локально проверяются загрузка, размеры и профиль сайта, но не реклама и не другие функции SDK.

Если что-то не так

Пустая страница или ошибки модулей в консоли
Страница открыта через file://. Запустите сервер и откройте адрес http://localhost:….
«Address already in use» при запуске сервера
Порт занят, например сервером из другого окна. Запустите на другом порту: python tools/server.py 5510.
В cgframe.html ничего не загружается
Сборки ещё нет. Сначала выполните python tools/build_cg.py: рамка открывает ../dist/crazygames/index.html.
В рамке старая версия игры
Пересоберите архив через build_cg.py и нажмите Reload.
build_cg.py остановился с ошибкой
Какая-то страница или модуль грузит файл по абсолютному пути (/… или http…). На портале игра лежит в своей папке на CDN, поэтому все пути должны быть относительными. Скрипт пишет, какой файл и какой путь виноваты.
