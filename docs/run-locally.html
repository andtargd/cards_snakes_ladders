Запуск игры локально

Cards, Snakes & Ladders: обычная веб-версия и версия для CrazyGames. Все команды выполняются из корня проекта.

Что нужно

  • Python 3: на нём работают и сервер, и сборка.
  • Любой современный браузер.
  • npm, Node и сборщик не нужны. three.js и PeerJS уже лежат в vendor/, с CDN ничего не грузится. Исключение одно: сборка для CrazyGames грузит SDK портала с sdk.crazygames.com.
  • Node.js нужен только для relay-сервера комнат (server/relay/, шаг 4).

1 Веб-версия (как на GitHub Pages)

Запустите сервер и не закрывайте терминал:

python tools/server.py 5500

Откройте http://localhost:5500/.

Двойной клик по index.html не сработаетЧерез file:// браузер не загрузит ES-модули, поэтому нужен сервер.
Порт занят?Возьмите другой, например python tools/server.py 5510, и замените порт во всех ссылках ниже.

Подойдёт и любой статический сервер (python -m http.server 8765), но с tools/server.py работают ещё и все тестовые страницы из tools/.

2 Версия для CrazyGames

Есть два способа: быстрый, без сборки, и полный, с настоящим архивом.

Быстро · без сборки

Профиль CrazyGames

Добавьте к обычной странице параметр:

localhost:5500/?platform=crazygames

Подходит, чтобы проверять поведение игры. Изменения в коде видны сразу после перезагрузки. SDK CrazyGames страница загрузит сама.

Полный · со сборкой

Архив + рамка портала

Собирается настоящий zip, затем сборка открывается в iframe тех размеров, на которых тестирует CrazyGames.

Подходит для проверки перед загрузкой на портал.

Полная проверка по шагам

  1. Соберите архив: 
    python tools/build_cg.py
    Скрипт остановится с ошибкой, если что-то грузится по абсолютному пути. В конце он печатает число файлов и размер.
  2. Проверьте, что сервер из шага 1 запущен.
  3. Откройте рамку: localhost:5500/tools/cgframe.html. Справа вверху показано время до появления меню.
  4. Пройдите по размерам из выпадающего списка. Если рамка больше окна, включите fit. Кнопка Reload перезапускает игру.
  5. Загрузите dist/crazygames.zip на портал CrazyGames.
Сборка не обновляется самаПосле каждого изменения кода снова запустите build_cg.py, иначе в рамке будет старая версия.

Снимки всех экранов на всех размерах

tools/shots.html по очереди открывает игру (по умолчанию index.html; сборку — с src=) в рамке каждого размера при DPR 1, выводит на экран меню, Solo Play, Pass & Play, Online, How to Play, The Cards, партию на 6 игроков на поле 100, руку из 4 карт, выбор цели, лог, конец партии, игровое меню и другие, и сохраняет PNG в tmp/shots/now/. Полный прогон (10 размеров QA и 3 телефонных) идёт около 12 минут.

Обложки и видео для подачи

tools/covers.html рисует обложки из сцены игры (доска, змеи, лестницы, пешки, веер карт и название) в трёх композициях: climb, slant, close, каждую в размерах 1920x1080, 800x1200 и 800x800. Без параметра out файлы ложатся в tmp/covers/; out=docs/crazygames/media сохраняет их рядом с остальными материалами подачи, out=0 только показывает. v=slant оставляет одну композицию, numbers=1 возвращает номера клеток (по умолчанию их нет: на обложке не должно быть текста, кроме названия).

tools/trailer.html играет партию по сценарию (лестница, Swap Places, змея, бросок к финишу) и записывает её с canvas игры, без курсора и звука; первые полсекунды показывают обложку. Сценарий одинаковый для обоих форматов, ролик длится 19,6 с.

ПараметрЧто делает
size=1080x1620формат ролика: 1920x1080 (по умолчанию) или 1080x1620
rec=framesкаждый кадр в JPEG, в tmp/trailer/<размер>/, потом ffmpeg (по умолчанию; ровные 30 кадров в секунду на любой машине)
rec=webmзапись через MediaRecorder в реальном времени, файл tmp/trailer/trailer-<размер>.webm
rec=noneтолько сыграть сценарий и показать тайминг
every=10сохранить только каждый десятый кадр, для быстрого просмотра

Кадры в mp4 (H.264, без звука) и webm собираются так:

ffmpeg -framerate 30 -i tmp/trailer/1920x1080/f%05d.jpg -c:v libx264 -pix_fmt yuv420p -crf 18 -preset slow -movflags +faststart -an docs/crazygames/media/trailer-1920x1080.mp4
ffmpeg -framerate 30 -i tmp/trailer/1920x1080/f%05d.jpg -c:v libvpx-vp9 -b:v 0 -crf 30 -row-mt 1 -pix_fmt yuv420p -an docs/crazygames/media/trailer-1920x1080.webm

Видео в git не попадают (.gitignore), обложки 3 размеров композиции slant лежат в docs/crazygames/media/. Для трейлера игра понимает ?clock=manual: она не крутит кадры сама, их шагает страница записи.

Онлайн с SDK CrazyGames

SDK подключён без рекламы (web/platform.js): loadingStart/Stop вокруг загрузки, gameplayStart/Stop, пока на экране идёт партия (не меню и не законченная партия), happytime при победе, а для онлайна ссылка-приглашение, комната и её доступность для портала, instant multiplayer, приглашение с портала, пока игра открыта. Реклама, user и data пока не подключены. Локальный SDK пишет в консоль «Requesting gameplay start (local)» и т. п. На localhost SDK работает в локальном режиме: ссылка ведёт на заглушку crazygames.com/game/your-game-will-appear-here, а приглашения и instant multiplayer изображаются параметрами в адресе сборки. В cgframe они дописываются к полю build, например ../dist/crazygames/index.html?instantJoin=true.

Параметр сборкиЧто изображает
?instantJoin=trueinstant multiplayer: игра сразу открывает свою комнату (режим и поле из экрана Online)
?roomId=КОД или ?czy_invite=true&roomId=КОДигрок пришёл по ссылке-приглашению: сразу входит в комнату КОД (вместе с instantJoin=true тоже)
?debugкаждый вызов хука в консоли: roomOpened КОД true/false, roomClosed

Локальный SDK пишет в консоль, что он сделал: «Invite link is …», «Update room (local) with params …», «Left room (local)». Приглашение с портала, пока игра открыта, локальный SDK не присылает: в консоли игры (внутри рамки) его заменяет __cslInvite('КОД').

Если SDK не загрузился(блокировщик рекламы, нет сети) игра работает как раньше: в консоли предупреждение «no CrazyGames SDK», в комнату входят только по коду, под Create a Room написано «Get a room code for friends». Проверить можно копией сборки, где адрес SDK заменён на несуществующий.

4 Версия для Discord (Activity)

Профиль discord в web/platform.js загружает web/discord.js, а тот — SDK Discord из vendor/discord/. Внутри Discord комната — это канал: instanceId активности превращается в код комнаты из 5 букв, у всех в канале он одинаковый. Внешние серверы (PeerJS, MQTT-брокеры) идут через URL Mappings, их список — MAPPINGS в web/discord.js; каждую строку оттуда нужно добавить в Developer Portal.

Без Discord: mock

АдресЧто будет
?platform=discordпрофиль discord без SDK: в консоли «no Discord SDK», игра работает как на Pages
?platform=discord&mockInstance=ABCSDK подменён объектом с instanceId ABC: в консоли «[discord] mock» и код комнаты, вызовы хуков видны. Два окна с одним mockInstance получают одну комнату

Сборка

python tools/build_discord.py

Собирает dist/discord/: в index.html добавлено window.CSL_PLATFORM = 'discord', все пути относительные, ничего не грузится снаружи (скрипт остановится, если найдёт внешний адрес). Общий код сборок — tools/webbuild.py. Запуск сборки локально (папка отдаётся как корень, адрес localhost:5560/?mockInstance=ABC&debug):

python tools/server.py 5560 dist/discord

Сборка в настоящем Discord

cloudflared tunnel --url http://localhost:5560

В Portal → Activities → URL Mappings: корневое сопоставление / → адрес туннеля без https://, плюс строки из MAPPINGS. Запустите активность из голосового канала: игра доходит до меню. Мгновенный вход за стол канала появится в задаче 4 плана (docs/discord/launch-plan.md); пока первый игрок в канале видит «комната не найдена» на экране Online.

Relay-сервер комнат

В Discord комнаты идут не через PeerJS и брокеры, а через свой сервер server/relay/ (Cloudflare Worker, одна комната — один Durable Object). Он только пересылает сообщения, логика комнат прежняя: хост — браузер игрока. Клиент — web/relaypeer.js, для web/net.js он выглядит как PeerJS. Профиль discord включает его сам, на любом другом сайте — параметр ?server=ws://127.0.0.1:8787. Для запуска нужен Node.js (только для сервера, игре он не нужен):

cd server/relay
npm install
npm run dev

Сервер слушает ws://127.0.0.1:8787. Проверка: nettest.html?server=ws://127.0.0.1:8787 (сценарии про брокеры пропускаются) и onlinetest.html?server=…; mock Discord с сервером: ?platform=discord&mockInstance=ABC (адрес сервера по умолчанию — локальный).

Выкладка: npx wrangler login (один раз, в браузере), затем npm run deploy в server/relay. Сейчас сервер выложен на csl-relay.csl-relay.workers.dev (поддомен workers.dev аккаунта — csl-relay): этот адрес записан в RELAY_HOST в web/discord.js, а в Portal нужна строка /x/relay → csl-relay.csl-relay.workers.dev. Если адрес изменится, поменяйте его в обоих местах.

Спайк Discord в настоящем Discord

Активность Discord всегда открывается с адреса /. Если после порта указать страницу, сервер отдаёт её на / вместо index.html (в .claude/launch.json это конфиг discord-spike):

python tools/server.py 5550 tools/discordspike.html
cloudflared tunnel --url http://localhost:5550

В Developer Portal → Activities → URL Mappings: / → адрес туннеля (без https://), а для тестов ещё /x/peerjs → 0.peerjs.com, /x/emqx → broker.emqx.io:8084, /x/mosq → test.mosquitto.org:8081, /x/echo → echo.websocket.org. Запустите активность в голосовом канале на компьютере и на телефоне (на мобильном интернете). Client ID страница берёт из адреса <id>.discordsays.com. Внизу страницы — отчёт и кнопка Copy report, в списке «Blocked by CSP» видно, что запретил Discord.

Если что-то не так

Пустая страница или ошибки модулей в консоли
Страница открыта через file://. Запустите сервер и откройте адрес http://localhost:….
«Address already in use» при запуске сервера
Порт занят, например сервером из другого окна. Запустите на другом порту: python tools/server.py 5510.
В cgframe.html ничего не загружается
Сборки ещё нет. Сначала выполните python tools/build_cg.py: рамка открывает ../dist/crazygames/index.html.
В рамке старая версия игры
Пересоберите архив через build_cg.py и нажмите Reload.
build_cg.py остановился с ошибкой
Какая-то страница или модуль грузит файл по абсолютному пути (/… или http…). На портале игра лежит в своей папке на CDN, поэтому все пути должны быть относительными; с другого сервера можно грузить только SDK CrazyGames. Скрипт пишет, какой файл и какой путь виноваты.
В консоли «no CrazyGames SDK»
SDK не загрузился или не ответил за 10 с: блокировщик рекламы, нет сети или домен не CrazyGames и не localhost. Игра работает дальше, комнаты только по коду. Локально открывайте сборку через localhost или 127.0.0.1.
