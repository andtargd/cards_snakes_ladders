# Discord: план выхода (Activity)

Цель — запустить игру как Discord Activity: её открывают прямо в голосовом канале, и все, кто там сидит, играют за одним столом. Порядок такой:
- **MVP** — игра работает в Discord для нас и друзей (приложение не в каталоге): запускается в канале, все участники попадают в одну партию без кодов, имена берутся из Discord, онлайн работает стабильно;
- **развитие** — приглашения, presence, каталог App Directory, монетизация, статистика (раздел «После MVP»).

Условия:
- GitHub Pages, сборка CrazyGames и пакет Project 0 продолжают работать из того же `main`;
- всё, что относится к Discord, подключается через профиль и хуки `web/platform.js`, как CrazyGames. Ядро в `experience/` о Discord не знает.

Документация: <https://discord.com/developers/docs/activities/overview>, SDK: <https://github.com/discord/embedded-app-sdk>

## Архитектурный принцип

```
experience/            ядро игры: правила, UI, звук. Знает только p0 / p0.web
web/platform.js        профиль 'discord' + provide({...}) для его хуков
web/discord.js         (новое) Discord SDK: ready, instanceId, авторизация, участники, внешние ссылки
web/net.js             транспорт комнат; к data channel и MQTT добавится ещё один тип связи (relay-сервер)
vendor/discord/        (новое) ESM-сборка @discord/embedded-app-sdk, без CDN
server/relay/          (новое) маленький сервер: WebSocket-релей комнат + обмен OAuth-кода на токен
tools/build_discord.py (новое) сборка dist/discord/
```

Что важно знать про Discord:
- Активность работает в iframe на `https://<app_id>.discordsays.com` со строгой CSP. Обращаться можно **только** к своему домену. Внешние адреса подключаются через URL Mappings в Developer Portal (префикс `/x/...` → внешний хост) и `patchUrlMappings` из SDK.
- Комната — это `discordSdk.instanceId`: у всех, кто запустил активность в одном канале, он одинаковый. Он становится кодом комнаты, хостом остаётся браузер игрока, как сейчас.
- Чтобы получить имя и аватар, нужен OAuth: `authorize` → наш сервер меняет code на токен (client secret хранится только на сервере) → `authenticate`.

## Общие правила для каждой задачи

1. Перед чтением кода — `graphify query "<вопрос>"` (правило из CLAUDE.md). После правок — `graphify update .`.
2. Не ломать: GitHub Pages (`index.html`), CrazyGames (`tools/build_cg.py`, `?platform=crazygames`), Project 0 (`tools/harness.html`), онлайн-комнаты и Quick Match.
3. Проверка вне Discord: dev-сервер `python tools/server.py 5500` ("dev" в `.claude/launch.json`), `?platform=discord` с подменой SDK (mock из задачи 2). В Discord — через туннель (задача 0). В консоли не должно быть ошибок.
4. Тексты в UI только на английском, все строки — в `experience/strings.js`.
5. Работать в ветке `dc/<slug>` от свежего `main`. В конце коммит в эту ветку, без пуша. Коротко отчитаться: что изменено, что проверено, что не проверено (особенно что проверено только в mock, а не в настоящем Discord).
6. Если задача меняет сервер, сборку или тестовые страницы — обновить `docs/run-locally.html`.
7. Секреты (client secret, токены) не попадают в репозиторий и в клиентский код: только в переменные окружения сервера, пример — в `server/relay/.env.example`.

### Задача 3. Relay-сервер и новый тип связи в net.js

```text
Задача 3 из docs/discord/launch-plan.md: следуй «Общим правилам» оттуда. Задачи 1–2 сделаны. Выводы спайка: <вставить>.

Цель — в Discord все сообщения комнаты идут через наш WebSocket-сервер; логика комнат (хост-браузер, звезда, передача хоста, боты на место ушедших) не меняется.
```

## Чек-лист MVP

- [ ] активность запускается в голосовом канале на компьютере, в браузере и на телефоне
- [ ] все в канале попадают за один стол без кодов; второй канал — свой стол
- [ ] уход хоста посреди партии: игра продолжается, его место занимает бот
- [ ] обрыв сети на телефоне и возврат — игрок снова на своём месте
- [ ] имена и аватары из Discord; отказ от авторизации не ломает игру
- [ ] в консоли нет CSP-ошибок; внешние ссылки открываются через Discord
- [ ] читается в PiP и на телефоне, звук по умолчанию тихий
- [ ] секретов нет в репозитории и в dist/
- [ ] privacy policy и ToS указаны в Portal
- [ ] Pages, CrazyGames и Project 0 работают из того же main
