1 Влить ветку в main 2 мин

Код, с которого собрана выложенная игра, лежит в ветке dc/release. Дальше всё выкладываем из main.

Напиши мне: «смёржи dc/release в main и запушь». Или сам:

git checkout main
git merge dc/release
git push

GitHub Pages пересоберётся за минуту; сама игра на Pages не меняется (в ветке — серверы, документы и тестовые страницы).

5 Позвать друзей 10 мин + ожидание

Пока приложение не верифицировано, Discord запускает активность только на серверах меньше 25 участников — на сервере CSL так и есть, просто не зови больше.

Создай текстовый канал #баги (правый клик по категории → Создать канал): туда друзья пишут о проблемах.

Правый клик по серверу CSL → Пригласить людей → скопировать ссылку → отправить 3–5 друзьям.

  2. Для каждого друга: его имя пользователя в Discord (не отображаемое имя, а username) → Пригласить. До 50 человек.
  3. Каждому придёт письмо на почту от Discord — он должен нажать в нём Accept. Пока не принял, активности он не увидит. В списке на этой странице видно, кто принял.

Тест игры «Cards, Snakes & Ladders» в Discord — минут 20–30.

Перед тестом:
• прими приглашение тестировщика — оно пришло на почту от Discord (кнопка Accept);

Тест:

7 Позже, по желанию: dev-приложение для туннеля 10 мин

Нужно, когда захочешь проверить изменения в настоящем Discord до того, как их увидят друзья. У приложения Discord один набор сопоставлений, поэтому туннель живёт в отдельном приложении, а продакшен не трогаем. Сервер комнат уже умеет пускать оба.

  1. Applications → New Application → имя Cards, snakes and ladders (dev).
  2. Активности → Настройки → Подключить активности.
  3. Сопоставления URL-адресов: те же пять /x/…, что в шаге 2.2. Корневое — заполнишь в 7.4.
  1. Новое приложение → OAuth2 → скопируй Client ID и пришли мне: «dev client id: …». Я впишу его в server/relay/wrangler.toml.
  2. Там же Reset Secret → скопируй секрет и сам положи его на сервер (в чат его не присылай): 
    cd server/relay
npx wrangler secret put DISCORD_DEV_CLIENT_SECRET
    Команда попросит вставить секрет — вставь и нажми Enter.
  3. Напиши мне «секрет положил» — я выложу сервер комнат с новым приложением (когда никто не играет).

Владелец приложения запускает его и так; друзей в dev-приложение не зови. Установи его на сервер CSL по ссылке https://discord.com/oauth2/authorize?client_id=<dev client id>.

  1. Мне: «подними discord-сборку для туннеля» — я соберу dist/discord/ и запущу её на порту 5560.
  2. Сам (мне запуск туннелей запрещён), в отдельном окне терминала: 
    cloudflared tunnel --url http://localhost:5560
    Скопируй адрес вида xxxx.trycloudflare.com из вывода.
  3. Portal dev-приложения → Сопоставления URL-адресов → Корневое → этот адрес (без https://) → сохранить.
  4. Запусти в Discord активность (dev), не основную.
